1. Qu'est-ce que SQL ?

📂 Base de données : photography_db

SQL signifie Structured Query Language (langage de requête structuré). C'est le langage que vous utilisez pour parler à une base de données — poser des questions, récupérer des données, ajouter de nouveaux enregistrements, ou faire des modifications.

Notre base de données s'appelle photography_db. Elle contient des photographes de 20 pays, leurs séances à travers le monde, et l'équipement qu'ils possèdent. Ce sont les mêmes données que celles utilisées dans le cours Python — deux langages, un seul jeu de données.

Termes ClésUne base de données est un ensemble de données organisées. Une table est un ensemble de données liées à l'intérieur. Une ligne est un enregistrement. Une colonne est une information sur cet enregistrement.

2. SELECT — Lire les Données

📂 Table : photographers

La commande SQL la plus importante est SELECT. Vous l'utiliserez dans presque toutes les requêtes que vous écrirez. Elle indique à la base de données quelles colonnes vous voulez voir.

-- Récupérer toutes les colonnes de la table photographers SELECT * FROM photographers;
-- Récupérer seulement le nom et le pays SELECT name, country FROM photographers;
Résultat
namecountry
Amara DialloSenegal
Carlos MendezBrazil
Priya NairIndia
James OkonkwoNigeria
-- Renommer une colonne dans le résultat avec AS SELECT name AS photographer, specialty AS type_of_work, rating FROM photographers;
Utilisez * avec parcimonie. SELECT * retourne toutes les colonnes. C'est bien pour explorer, mais dans de vraies requêtes, ne listez que les colonnes dont vous avez réellement besoin.

Écrivez des requêtes qui retournent :

  2. Toutes les colonnes de photographers — utilisez *
  3. Nom, spécialité et years_experience — renommez years_experience en experience

3. WHERE — Filtrer

📂 Table : shoots

WHERE filtre vos résultats. Au lieu de chaque ligne, vous n'obtenez que les lignes qui correspondent à votre condition. Pensez-y comme la question après « montre-moi seulement... ».

-- Seulement les séances à Dakar SELECT event, location, year FROM shoots WHERE location = 'Dakar';
-- Seulement les séances après 2020 SELECT event, year, photos_taken FROM shoots WHERE year > 2020;
-- Combiner deux conditions avec AND SELECT event, location, year FROM shoots WHERE location = 'Dakar' AND year > 2020;
