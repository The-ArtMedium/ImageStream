1. Variáveis e Tipos de Dados

📂 Conjunto de dados usado nesta lição: photographers.csv

Pense em uma Variável como o rótulo de um rolo de filme. Ela diz ao Python o que há dentro.

# Definindo nossas primeiras variáveis de dados fotográficos photo_name = "World_Cup_Final_001.jpg" shutter_speed = "1/1000" iso = 800 camera_body = "Canon R5" # Imprimi-las print(photo_name) print("ISO was:", iso)

Python armazena três tipos principais de dados que você usará constantemente:

# Texto (chamado de string) photographer = "Satdiva" # Número (chamado de inteiro) total_shots = 61833 # total real de todas as 103 sessões # Verdadeiro / Falso (chamado de booleano) is_raw = True
Quando você tem as bases, tudo se torna óbvio. Variáveis são a base. Tudo mais em Python se constrói sobre isso.

2. Listas e Dicionários

📂 Conjunto de dados usado nesta lição: photographers.csv · shoots.csv

Uma Lista é como uma folha de contato. Ela guarda muitos itens em um lugar em uma ordem específica.

equestrian_events = ["Show Jumping", "Dressage", "Polo"] # Obter o primeiro item (Python conta a partir de 0) print(equestrian_events[0]) # → "Show Jumping" print(equestrian_events[2]) # → "Polo" # Quantos itens? print(len(equestrian_events)) # → 3

Um Dicionário é como uma bolsa de câmera. Cada item tem um nome (chave) e um valor.

photographer = { "name": "Amara Diallo", "country": "Senegal", "specialty": "Wildlife", "total_shoots": 4 } # Acessar pelo nome da chave print(photographer["name"]) # → "Amara Diallo" print(photographer["specialty"]) # → "Wildlife"
Pense assim: Uma Lista é ordenada como um rolo de filme. Um Dicionário é rotulado como um arquivo.

3. Loops e Lógica

📂 Conjunto de dados usado nesta lição: shoots.csv

Um Loop permite que o Python repita uma tarefa automaticamente — como processar cada foto de uma pasta sem fazer uma por uma.

shots = ["IMG_001.jpg", "IMG_002.jpg", "IMG_003.jpg"] for shot in shots: print("Processando:", shot) # Resultado: # Processando: IMG_001.jpg # Processando: IMG_002.jpg # Processando: IMG_003.jpg

A lógica (if / else) permite que o Python tome decisões baseadas em dados.

iso = 3200 if iso > 1600: print("ISO alto — verificar ruído") elif iso > 800: print("ISO médio — aceitável") else: print("ISO limpo — qualidade excelente")
Poder combinado: Percorra cada sessão. Para cada uma, verifique o ISO. Marque as ruidosas automaticamente.

4. Funções

📂 Conjunto de dados usado nesta lição: shoots.csv · equipment.csv

Uma Função é uma ferramenta reutilizável que você constrói uma vez e usa para sempre. Como uma lente — você compra uma vez, usa em qualquer corpo de câmera.

# Definir a função uma vez def describe_shoot(event, location, shots_taken): print(f"Event: {event}") print(f"Location: {location}") print(f"Total shots: {shots_taken}") # Use quantas vezes precisar describe_shoot("Serengeti Safari", "Shanghai", 652) describe_shoot("Wildlife Reserve Shoot", "Kyiv", 165)

Funções também podem retornar um valor — como o resultado de um cálculo.

def keeper_rate(total, keepers): rate = (keepers / total) * 100 return round(rate, 1) result = keeper_rate(840, 92) print(f"Keeper rate: {result}%") # → Keeper rate: 11.0%
Regra geral: Se você escrever o mesmo código duas vezes, transforme-o em uma função.

5. Ler Arquivos CSV

📂 Conjunto de dados usado nesta lição: photographers.csv

CSV significa Comma-Separated Values (valores separados por vírgula). Os dados do seu arquivo vivem em arquivos CSV. Esta lição mostra como abri-los e lê-los com Python.

import csv # Abrir o conjunto de dados photographers with open("photographers.csv", "r") as file: reader = csv.DictReader(file) for row in reader: print(row["name"], "—", row["specialty"])

Estrutura de photographers.csv

photographer_id, name, country, specialty 1, Amara Diallo, Senegal, Wildlife 2, Carlos Mendez, Brazil, Street 3, Priya Nair, India, Portrait
DictReader lê cada linha como um dicionário — então você acessa as colunas pelo nome, não pela posição. Muito mais fácil de ler.

6. DataFrames do Pandas

📂 Conjunto de dados usado nesta lição: photographers.csv · shoots.csv

Pandas é uma biblioteca de Python que transforma seu CSV em uma tabela poderosa que você pode consultar como um banco de dados.

import pandas as pd # Carregar o conjunto de dados df = pd.read_csv("shoots.csv") # Ver as primeiras 5 linhas print(df.head()) # Quantas linhas e colunas? print(df.shape) # → (103, 10) # Nomes das colunas print(df.columns)

shoots.csv structure

shoot_id, photographer_id, event, location, year, photos_taken, photos_exported 1, 1, Serengeti Safari, Shanghai, 2021, 652, 132 2, 1, Wildlife Reserve Shoot, Kyiv, 2024, 165, 100 3, 1, Migration Season, Kolkata, 2023, 744, 128
103 linhas — esse é todo o seu arquivo. Pandas lida com isso instantaneamente, sejam 103 linhas ou 103 milhões.

7. Filtrar Sessões

📂 Conjunto de dados usado nesta lição: shoots.csv

Filtrar permite que você faça perguntas aos seus dados. Quais sessões foram em Dakar? Qual ano teve mais fotos tiradas? Encontre-as em uma linha.

import pandas as pd df = pd.read_csv("shoots.csv") # Todas as sessões em Dakar dakar = df[df["location"] == "Dakar"] print(dakar) # Todas as sessões depois de 2020 recent = df[df["year"] > 2020] print(recent.head()) # Sessões com mais de 1000 fotos tiradas heavy = df[df["photos_taken"] > 1000] print(f"Heavy shoots: {len(heavy)}")

Combine filtros usando & (e) ou | (ou):

# Dakar E depois de 2020 filtered = df[(df["location"] == "Dakar") & (df["year"] > 2020)] print(filtered)
Este é o poder. Mesmo com 103 dados, uma linha de código vence rolar por uma planilha — e isso escala para milhões da mesma forma.

8. Visualização

📂 Conjunto de dados usado nesta lição: shoots.csv · photographers.csv

Matplotlib transforma seus dados em gráficos. Veja seu arquivo rapidamente — sessões por ano, locais, taxas de retenção.

import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv("shoots.csv") # Contar sessões por ano by_year = df.groupby("year")["shoot_id"].count() # Plotar by_year.plot(kind="bar", color="#6bcf8a") plt.title("Sessões Por Ano") plt.xlabel("Ano") plt.ylabel("Número de Sessões") plt.tight_layout() plt.show()
