1. المتغيرات وأنواع البيانات

📂 مجموعة البيانات المستخدمة في هذا الدرس: photographers.csv

فكّر في المتغيّر كالملصق على علبة فيلم. يخبر Python بما بداخلها.

# تعريف أول متغيرات بيانات الصور لدينا photo_name = "World_Cup_Final_001.jpg" shutter_speed = "1/1000" iso = 800 camera_body = "Canon R5" # طباعتها print(photo_name) print("ISO was:", iso)

يخزّن Python ثلاثة أنواع رئيسية من البيانات ستستخدمها باستمرار:

# نص (يُسمى string) photographer = "Satdiva" # رقم (يُسمى integer) total_shots = 61833 # الإجمالي الحقيقي عبر كل الـ103 جلسة # صح / خطأ (يُسمى boolean) is_raw = True
عندما ترسي الأساس، يصبح كل شيء واضحاً. المتغيرات هي الأساس. كل شيء آخر في Python يُبنى على هذا.

2. القوائم والقواميس

📂 مجموعة البيانات المستخدمة في هذا الدرس: photographers.csv · shoots.csv

القائمة مثل ورقة التلامس. تحتفظ بعناصر كثيرة في مكان واحد وبترتيب محدد.

equestrian_events = ["Show Jumping", "Dressage", "Polo"] # الحصول على أول عنصر (Python يعد من 0) print(equestrian_events[0]) # → "Show Jumping" print(equestrian_events[2]) # → "Polo" # كم عدد العناصر؟ print(len(equestrian_events)) # → 3

القاموس مثل حقيبة الكاميرا. كل عنصر له اسم (مفتاح) وقيمة.

photographer = { "name": "Amara Diallo", "country": "Senegal", "specialty": "Wildlife", "total_shoots": 4 } # الوصول عبر اسم المفتاح print(photographer["name"]) # → "Amara Diallo" print(photographer["specialty"]) # → "Wildlife"
فكّر بها هكذا: القائمة مرتبة كبكرة فيلم. القاموس مُسمّى كخزانة ملفات.

3. الحلقات والمنطق

📂 مجموعة البيانات المستخدمة في هذا الدرس: shoots.csv

الحلقة تتيح لـ Python تكرار مهمة تلقائياً — مثل معالجة كل صورة في مجلد دون فعل ذلك واحدة تلو الأخرى.

shots = ["IMG_001.jpg", "IMG_002.jpg", "IMG_003.jpg"] for shot in shots: print("معالجة:", shot) # الناتج: # معالجة: IMG_001.jpg # معالجة: IMG_002.jpg # معالجة: IMG_003.jpg

المنطق (if / else) يتيح لـ Python اتخاذ قرارات بناءً على البيانات.

iso = 3200 if iso > 1600: print("ISO مرتفع — تحقق من التشويش") elif iso > 800: print("ISO متوسط — مقبول") else: print("ISO نظيف — جودة ممتازة")
القوة المجتمعة: مرّ عبر كل جلسة. لكل واحدة، تحقق من ISO. صنّف المشوَّشة تلقائياً.

4. الدوال

📂 مجموعة البيانات المستخدمة في هذا الدرس: shoots.csv · equipment.csv

الدالة أداة قابلة لإعادة الاستخدام تبنيها مرة واحدة وتستخدمها للأبد. مثل العدسة — تشتريها مرة واحدة، وتستخدمها على أي جسم كاميرا.

# تعريف الدالة مرة واحدة def describe_shoot(event, location, shots_taken): print(f"Event: {event}") print(f"Location: {location}") print(f"Total shots: {shots_taken}") # استخدمها بقدر ما تحتاج describe_shoot("Serengeti Safari", "Shanghai", 652) describe_shoot("Wildlife Reserve Shoot", "Kyiv", 165)

يمكن للدوال أيضاً إرجاع قيمة — مثل نتيجة حساب.

def keeper_rate(total, keepers): rate = (keepers / total) * 100 return round(rate, 1) result = keeper_rate(840, 92) print(f"Keeper rate: {result}%") # → Keeper rate: 11.0%
قاعدة عامة: إذا كتبت نفس الكود مرتين، حوّله إلى دالة.

5. قراءة ملفات CSV

📂 مجموعة البيانات المستخدمة في هذا الدرس: photographers.csv

CSV تعني Comma-Separated Values (قيم مفصولة بفواصل). بيانات أرشيفك تعيش في ملفات CSV. يُظهر هذا الدرس كيفية فتحها وقراءتها باستخدام Python.

import csv # فتح مجموعة بيانات photographers with open("photographers.csv", "r") as file: reader = csv.DictReader(file) for row in reader: print(row["name"], "—", row["specialty"])

بنية photographers.csv

photographer_id, name, country, specialty 1, Amara Diallo, Senegal, Wildlife 2, Carlos Mendez, Brazil, Street 3, Priya Nair, India, Portrait
DictReader يقرأ كل صف كقاموس — لذا تصل إلى الأعمدة بالاسم، وليس بالموضع. أسهل بكثير للقراءة.

6. DataFrames في Pandas

📂 مجموعة البيانات المستخدمة في هذا الدرس: photographers.csv · shoots.csv

Pandas مكتبة Python تحوّل CSV إلى جدول قوي يمكنك الاستعلام عنه كقاعدة بيانات.

import pandas as pd # تحميل مجموعة البيانات df = pd.read_csv("shoots.csv") # رؤية أول 5 صفوف print(df.head()) # كم عدد الصفوف والأعمدة؟ print(df.shape) # → (103, 10) # أسماء الأعمدة print(df.columns)

shoots.csv structure

shoot_id, photographer_id, event, location, year, photos_taken, photos_exported 1, 1, Serengeti Safari, Shanghai, 2021, 652, 132 2, 1, Wildlife Reserve Shoot, Kyiv, 2024, 165, 100 3, 1, Migration Season, Kolkata, 2023, 744, 128
103 صفوف — هذا هو أرشيفك بالكامل. Pandas يتعامل معه فوراً، سواء كان 103 صفوف أو 103 مليون.

7. تصفية الجلسات

📂 مجموعة البيانات المستخدمة في هذا الدرس: shoots.csv

التصفية تتيح لك طرح أسئلة على بياناتك. ما الجلسات التي كانت في داكار؟ أي سنة شهدت أكبر عدد صور؟ اعثر عليها في سطر واحد.

import pandas as pd df = pd.read_csv("shoots.csv") # كل الجلسات في داكار dakar = df[df["location"] == "Dakar"] print(dakar) # كل الجلسات بعد 2020 recent = df[df["year"] > 2020] print(recent.head()) # الجلسات بأكثر من 1000 صورة ملتقطة heavy = df[df["photos_taken"] > 1000] print(f"Heavy shoots: {len(heavy)}")

ادمج التصفيات باستخدام & (و) أو | (أو):

# داكار و بعد 2020 filtered = df[(df["location"] == "Dakar") & (df["year"] > 2020)] print(filtered)
هذه هي القوة. حتى مع 103 سجل، سطر كود واحد يتفوق على تصفح جدول بيانات — ويتوسع إلى الملايين بنفس الطريقة.

8. التصوير البياني

📂 مجموعة البيانات المستخدمة في هذا الدرس: shoots.csv · photographers.csv

Matplotlib يحوّل بياناتك إلى رسوم بيانية. اطّلع على أرشيفك بلمحة — الجلسات لكل سنة، المواقع، معدلات الاحتفاظ.

import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv("shoots.csv") # عد الجلسات لكل سنة by_year = df.groupby("year")["shoot_id"].count() # رسمها by_year.plot(kind="bar", color="#6bcf8a") plt.title("الجلسات لكل سنة") plt.xlabel("السنة") plt.ylabel("عدد الجلسات") plt.tight_layout() plt.show()
لقد أكملت الأساسيات. المتغيرات ← القوائم ← الحلقات ← الدوال ← CSV ← Pandas ← التصفية ← التصوير البياني. هذا هو المسار الكامل. أرشيفك الآن قابل للبرمجة.
