1. Variables et Types de Données

📂 Jeu de données utilisé dans cette leçon : photographers.csv

Pensez à une Variable comme l'étiquette sur une bobine de film. Elle indique à Python ce qu'elle contient.

# Définir nos premières variables de données photo photo_name = "World_Cup_Final_001.jpg" shutter_speed = "1/1000" iso = 800 camera_body = "Canon R5" # Les afficher print(photo_name) print("ISO was:", iso)

Python stocke trois types de données principaux que vous utiliserez constamment :

# Texte (appelé une chaîne de caractères) photographer = "Satdiva" # Nombre (appelé un entier) total_shots = 61833 # vrai total sur les 103 séances # Vrai / Faux (appelé un booléen) is_raw = True
Une fois les fondations posées, tout devient évident. Les variables sont la fondation. Tout le reste de Python s'appuie sur cela.

2. Listes et Dictionnaires

📂 Jeu de données utilisé dans cette leçon : photographers.csv · shoots.csv

Une Liste est comme une planche-contact. Elle contient plusieurs éléments au même endroit, dans un ordre précis.

equestrian_events = ["Show Jumping", "Dressage", "Polo"] # Récupérer le premier élément (Python compte à partir de 0) print(equestrian_events[0]) # → "Show Jumping" print(equestrian_events[2]) # → "Polo" # Combien d'éléments ? print(len(equestrian_events)) # → 3

Un Dictionnaire est comme un sac photo. Chaque élément a un nom (clé) et une valeur.

photographer = { "name": "Amara Diallo", "country": "Senegal", "specialty": "Wildlife", "total_shoots": 4 } # Accéder par le nom de la clé print(photographer["name"]) # → "Amara Diallo" print(photographer["specialty"]) # → "Wildlife"
Pensez-y ainsi : Une Liste est ordonnée comme une pellicule. Un Dictionnaire est étiqueté comme un classeur.

3. Boucles et Logique

📂 Jeu de données utilisé dans cette leçon : shoots.csv

Une Boucle permet à Python de répéter une tâche automatiquement — comme traiter chaque photo d'un dossier sans le faire une par une.

shots = ["IMG_001.jpg", "IMG_002.jpg", "IMG_003.jpg"] for shot in shots: print("Traitement :", shot) # Résultat : # Traitement : IMG_001.jpg # Traitement : IMG_002.jpg # Traitement : IMG_003.jpg

La logique (if / else) permet à Python de prendre des décisions basées sur les données.

iso = 3200 if iso > 1600: print("ISO élevé — vérifier le bruit") elif iso > 800: print("ISO moyen — acceptable") else: print("ISO propre — excellente qualité")
Puissance combinée : Parcourez chaque séance. Pour chacune, vérifiez l'ISO. Signalez automatiquement celles qui sont bruitées.

4. Fonctions

📂 Jeu de données utilisé dans cette leçon : shoots.csv · equipment.csv

Une Fonction est un outil réutilisable que vous construisez une fois et utilisez pour toujours. Comme un objectif — vous l'achetez une fois, vous l'utilisez sur n'importe quel boîtier.

# Définir la fonction une seule fois def describe_shoot(event, location, shots_taken): print(f"Event: {event}") print(f"Location: {location}") print(f"Total shots: {shots_taken}") # Utilisez-la autant de fois que nécessaire describe_shoot("Serengeti Safari", "Shanghai", 652) describe_shoot("Wildlife Reserve Shoot", "Kyiv", 165)

Les fonctions peuvent aussi retourner une valeur — comme un résultat de calcul.

def keeper_rate(total, keepers): rate = (keepers / total) * 100 return round(rate, 1) result = keeper_rate(840, 92) print(f"Keeper rate: {result}%") # → Keeper rate: 11.0%
Règle générale : Si vous écrivez le même code deux fois, transformez-le en fonction.

5. Lire des Fichiers CSV

📂 Jeu de données utilisé dans cette leçon : photographers.csv

CSV signifie Comma-Separated Values (valeurs séparées par des virgules). Les données de votre archive vivent dans des fichiers CSV. Cette leçon vous montre comment les ouvrir et les lire avec Python.

import csv # Ouvrir le jeu de données photographers with open("photographers.csv", "r") as file: reader = csv.DictReader(file) for row in reader: print(row["name"], "—", row["specialty"])

Structure de photographers.csv

photographer_id, name, country, specialty 1, Amara Diallo, Senegal, Wildlife 2, Carlos Mendez, Brazil, Street 3, Priya Nair, India, Portrait
DictReader lit chaque ligne comme un dictionnaire — vous accédez donc aux colonnes par leur nom, pas par leur position. Bien plus facile à lire.

6. DataFrames Pandas

📂 Jeu de données utilisé dans cette leçon : photographers.csv · shoots.csv

Pandas est une bibliothèque Python qui transforme votre CSV en une table puissante que vous pouvez interroger comme une base de données.

import pandas as pd # Charger le jeu de données df = pd.read_csv("shoots.csv") # Voir les 5 premières lignes print(df.head()) # Combien de lignes et de colonnes ? print(df.shape) # → (103, 10) # Noms des colonnes print(df.columns)

shoots.csv structure

shoot_id, photographer_id, event, location, year, photos_taken, photos_exported 1, 1, Serengeti Safari, Shanghai, 2021, 652, 132 2, 1, Wildlife Reserve Shoot, Kyiv, 2024, 165, 100 3, 1, Migration Season, Kolkata, 2023, 744, 128
103 lignes — c'est votre archive complète. Pandas les traite instantanément, qu'il y ait 103 lignes ou 103 millions.

7. Filtrer les Séances

📂 Jeu de données utilisé dans cette leçon : shoots.csv

Le filtrage vous permet de poser des questions à vos données. Quelles séances ont eu lieu à Dakar ? Quelle année a eu le plus de photos prises ? Trouvez-les en une seule ligne.

import pandas as pd df = pd.read_csv("shoots.csv") # Toutes les séances à Dakar dakar = df[df["location"] == "Dakar"] print(dakar) # Toutes les séances après 2020 recent = df[df["year"] > 2020] print(recent.head()) # Séances avec plus de 1000 photos prises heavy = df[df["photos_taken"] > 1000] print(f"Heavy shoots: {len(heavy)}")

Combinez les filtres avec & (et) ou | (ou) :

# Dakar ET après 2020 filtered = df[(df["location"] == "Dakar") & (df["year"] > 2020)] print(filtered)
Voilà la puissance. Même avec 103 données, une ligne de code vaut mieux que de faire défiler une feuille de calcul — et cela s'adapte à des millions de la même façon.

8. Visualisation

📂 Jeu de données utilisé dans cette leçon : shoots.csv · photographers.csv

Matplotlib transforme vos données en graphiques. Visualisez votre archive d'un coup d'œil — séances par année, lieux, taux de conservation.

import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv("shoots.csv") # Compter les séances par année by_year = df.groupby("year")["shoot_id"].count() # Le tracer by_year.plot(kind="bar", color="#6bcf8a") plt.title("Séances Par Année") plt.xlabel("Année") plt.ylabel("Nombre de Séances") plt.tight_layout() plt.show()
