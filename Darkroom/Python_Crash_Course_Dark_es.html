1. Variables y Tipos de Datos

📂 Conjunto de datos usado en esta lección: photographers.csv

Piense en una Variable como la etiqueta de un rollo de película. Le dice a Python qué hay dentro.

# Definiendo nuestras primeras variables de datos fotográficos photo_name = "World_Cup_Final_001.jpg" shutter_speed = "1/1000" iso = 800 camera_body = "Canon R5" # Imprimirlas print(photo_name) print("ISO was:", iso)

Python almacena tres tipos principales de datos que usará constantemente:

# Texto (llamado string) photographer = "Satdiva" # Número (llamado entero) total_shots = 61833 # total real de las 103 sesiones # Verdadero / Falso (llamado booleano) is_raw = True
Una vez que tiene las bases, todo se vuelve obvio. Las variables son la base. Todo lo demás en Python se construye sobre esto.

2. Listas y Diccionarios

📂 Conjunto de datos usado en esta lección: photographers.csv · shoots.csv

Una Lista es como una hoja de contacto. Contiene muchos elementos en un solo lugar en un orden específico.

equestrian_events = ["Show Jumping", "Dressage", "Polo"] # Obtener el primer elemento (Python cuenta desde 0) print(equestrian_events[0]) # → "Show Jumping" print(equestrian_events[2]) # → "Polo" # ¿Cuántos elementos? print(len(equestrian_events)) # → 3

Un Diccionario es como una bolsa de cámara. Cada elemento tiene un nombre (clave) y un valor.

photographer = { "name": "Amara Diallo", "country": "Senegal", "specialty": "Wildlife", "total_shoots": 4 } # Acceder por el nombre de la clave print(photographer["name"]) # → "Amara Diallo" print(photographer["specialty"]) # → "Wildlife"
Piénselo así: Una Lista está ordenada como un rollo de película. Un Diccionario está etiquetado como un archivador.

3. Bucles y Lógica

📂 Conjunto de datos usado en esta lección: shoots.csv

Un Bucle permite que Python repita una tarea automáticamente — como procesar cada foto de una carpeta sin hacerlo una por una.

shots = ["IMG_001.jpg", "IMG_002.jpg", "IMG_003.jpg"] for shot in shots: print("Procesando:", shot) # Resultado: # Procesando: IMG_001.jpg # Procesando: IMG_002.jpg # Procesando: IMG_003.jpg

La lógica (if / else) permite que Python tome decisiones basadas en datos.

iso = 3200 if iso > 1600: print("ISO alto — revisar el ruido") elif iso > 800: print("ISO medio — aceptable") else: print("ISO limpio — calidad excelente")
Poder combinado: Recorra cada sesión. Para cada una, revise el ISO. Marque las ruidosas automáticamente.

4. Funciones

📂 Conjunto de datos usado en esta lección: shoots.csv · equipment.csv

Una Función es una herramienta reutilizable que construye una vez y usa para siempre. Como un lente — lo compra una vez, lo usa en cualquier cuerpo de cámara.

# Definir la función una vez def describe_shoot(event, location, shots_taken): print(f"Event: {event}") print(f"Location: {location}") print(f"Total shots: {shots_taken}") # Úsela tantas veces como necesite describe_shoot("Serengeti Safari", "Shanghai", 652) describe_shoot("Wildlife Reserve Shoot", "Kyiv", 165)

Las funciones también pueden devolver un valor — como el resultado de un cálculo.

def keeper_rate(total, keepers): rate = (keepers / total) * 100 return round(rate, 1) result = keeper_rate(840, 92) print(f"Keeper rate: {result}%") # → Keeper rate: 11.0%
Regla general: Si escribe el mismo código dos veces, conviértalo en una función.

5. Leer Archivos CSV

📂 Conjunto de datos usado en esta lección: photographers.csv

CSV significa Comma-Separated Values (valores separados por comas). Los datos de su archivo viven en archivos CSV. Esta lección le muestra cómo abrirlos y leerlos con Python.

import csv # Abrir el conjunto de datos photographers with open("photographers.csv", "r") as file: reader = csv.DictReader(file) for row in reader: print(row["name"], "—", row["specialty"])

Estructura de photographers.csv

photographer_id, name, country, specialty 1, Amara Diallo, Senegal, Wildlife 2, Carlos Mendez, Brazil, Street 3, Priya Nair, India, Portrait
DictReader lee cada fila como un diccionario — así accede a las columnas por nombre, no por posición. Mucho más fácil de leer.

6. DataFrames de Pandas

📂 Conjunto de datos usado en esta lección: photographers.csv · shoots.csv

Pandas es una biblioteca de Python que convierte su CSV en una tabla poderosa que puede consultar como una base de datos.

import pandas as pd # Cargar el conjunto de datos df = pd.read_csv("shoots.csv") # Ver las primeras 5 filas print(df.head()) # ¿Cuántas filas y columnas? print(df.shape) # → (103, 10) # Nombres de columnas print(df.columns)

shoots.csv structure

shoot_id, photographer_id, event, location, year, photos_taken, photos_exported 1, 1, Serengeti Safari, Shanghai, 2021, 652, 132 2, 1, Wildlife Reserve Shoot, Kyiv, 2024, 165, 100 3, 1, Migration Season, Kolkata, 2023, 744, 128
103 filas — esa es toda su archivo. Pandas lo maneja al instante, ya sean 103 filas o 103 millones.

7. Filtrar Sesiones

📂 Conjunto de datos usado en esta lección: shoots.csv

Filtrar le permite hacer preguntas a sus datos. ¿Qué sesiones fueron en Dakar? ¿Qué año tuvo más fotos tomadas? Encuéntrelas en una línea.

import pandas as pd df = pd.read_csv("shoots.csv") # Todas las sesiones en Dakar dakar = df[df["location"] == "Dakar"] print(dakar) # Todas las sesiones después de 2020 recent = df[df["year"] > 2020] print(recent.head()) # Sesiones con más de 1000 fotos tomadas heavy = df[df["photos_taken"] > 1000] print(f"Heavy shoots: {len(heavy)}")

Combine filtros usando & (y) o | (o):

# Dakar Y después de 2020 filtered = df[(df["location"] == "Dakar") & (df["year"] > 2020)] print(filtered)
Este es el poder. Incluso con 103 datos, una línea de código supera a desplazarse por una hoja de cálculo — y escala a millones de la misma manera.

8. Visualización

📂 Conjunto de datos usado en esta lección: shoots.csv · photographers.csv

Matplotlib convierte sus datos en gráficos. Vea su archivo de un vistazo — sesiones por año, ubicaciones, tasas de retención.

import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv("shoots.csv") # Contar sesiones por año by_year = df.groupby("year")["shoot_id"].count() # Graficarlo by_year.plot(kind="bar", color="#6bcf8a") plt.title("Sesiones Por Año") plt.xlabel("Año") plt.ylabel("Número de Sesiones") plt.tight_layout() plt.show()
