कोर्स रोडमैप

हम फ़ोटोग्राफ़रों, शूट्स और उपकरणों के एक असली डेटासेट का इस्तेमाल यह सीखने के लिए करेंगे कि अपने जीवनभर के काम को कैसे स्वचालित करें, व्यवस्थित करें, और सुरक्षित रखें।

हर पाठ पिछले पाठ पर बनता है। आख़िर में आप अपने ख़ुद के आर्काइव डेटा को क्वेरी, फ़िल्टर, और विज़ुअलाइज़ कर पाएँगे।

इस कोर्स का उपयोग कैसे करें: हर पाठ पढ़ें, कोड उदाहरणों को समझें, फिर जारी रखने के लिए अगला पाठ दबाएँ, या नीचे दिए गए कार्ड्स से सीधे किसी भी पाठ पर जाएँ।

1. वेरिएबल और डेटा प्रकार

📂 इस पाठ में इस्तेमाल डेटासेट: photographers.csv

वेरिएबल को फ़िल्म कैनिस्टर पर लगे लेबल की तरह समझें। यह Python को बताता है कि अंदर क्या है।

# अपने पहले फ़ोटो डेटा वेरिएबल परिभाषित करना photo_name = "World_Cup_Final_001.jpg" shutter_speed = "1/1000" iso = 800 camera_body = "Canon R5" # उन्हें प्रिंट करें print(photo_name) print("ISO was:", iso)

Python तीन मुख्य प्रकार के डेटा स्टोर करता है जिन्हें आप लगातार इस्तेमाल करेंगे:

# टेक्स्ट (जिसे string कहते हैं) photographer = "Satdiva" # संख्या (जिसे integer कहते हैं) total_shots = 61833 # सभी 103 शूट्स का असली कुल योग # सही / ग़लत (जिसे boolean कहते हैं) is_raw = True
जब आपकी नींव पक्की हो जाती है, तो सब कुछ स्पष्ट हो जाता है। वेरिएबल ही नींव हैं। Python में बाकी सब कुछ इसी पर बनता है।

2. लिस्ट और डिक्शनरी

📂 इस पाठ में इस्तेमाल डेटासेट: photographers.csv · shoots.csv

लिस्ट एक कॉन्टैक्ट शीट की तरह है। यह कई आइटम को एक जगह, एक तय क्रम में रखती है।

equestrian_events = ["Show Jumping", "Dressage", "Polo"] # पहला आइटम लें (Python 0 से गिनता है) print(equestrian_events[0]) # → "Show Jumping" print(equestrian_events[2]) # → "Polo" # कितने आइटम हैं? print(len(equestrian_events)) # → 3

डिक्शनरी एक कैमरा बैग की तरह है। हर आइटम का एक नाम (key) और एक मान (value) होता है।

photographer = { "name": "Amara Diallo", "country": "Senegal", "specialty": "Wildlife", "total_shoots": 4 } # key के नाम से एक्सेस करें print(photographer["name"]) # → "Amara Diallo" print(photographer["specialty"]) # → "Wildlife"
इसे ऐसे समझें: लिस्ट फ़िल्म रोल की तरह क्रमबद्ध होती है। डिक्शनरी फ़ाइल कैबिनेट की तरह लेबल की गई होती है।

3. लूप और लॉजिक

📂 इस पाठ में इस्तेमाल डेटासेट: shoots.csv

लूप Python को कोई काम अपने आप दोहराने देता है — जैसे किसी फ़ोल्डर की हर फ़ोटो को एक-एक करके किए बिना प्रोसेस करना।

shots = ["IMG_001.jpg", "IMG_002.jpg", "IMG_003.jpg"] for shot in shots: print("प्रोसेस हो रहा है:", shot) # आउटपुट: # प्रोसेस हो रहा है: IMG_001.jpg # प्रोसेस हो रहा है: IMG_002.jpg # प्रोसेस हो रहा है: IMG_003.jpg

लॉजिक (if / else) Python को डेटा के आधार पर फ़ैसले लेने देता है।

iso = 3200 if iso > 1600: print("ज़्यादा ISO — नॉइज़ जाँचें") elif iso > 800: print("मध्यम ISO — ठीक है") else: print("साफ़ ISO — बेहतरीन क्वालिटी")
मिली-जुली ताक़त: हर शूट पर लूप चलाएँ। हर एक के लिए, ISO जाँचें। नॉइज़ी वालों को अपने आप चिह्नित करें।

4. फ़ंक्शन

📂 इस पाठ में इस्तेमाल डेटासेट: shoots.csv · equipment.csv

फ़ंक्शन एक ऐसा टूल है जिसे आप एक बार बनाकर हमेशा इस्तेमाल करते हैं। जैसे एक लेंस — आप इसे एक बार ख़रीदते हैं, इसे किसी भी कैमरा बॉडी पर इस्तेमाल करते हैं।

# फ़ंक्शन को एक बार परिभाषित करें def describe_shoot(event, location, shots_taken): print(f"Event: {event}") print(f"Location: {location}") print(f"Total shots: {shots_taken}") # जितनी बार ज़रूरत हो इस्तेमाल करें describe_shoot("Serengeti Safari", "Shanghai", 652) describe_shoot("Wildlife Reserve Shoot", "Kyiv", 165)

फ़ंक्शन एक मान भी वापस कर सकते हैं — जैसे किसी गणना का नतीजा।

def keeper_rate(total, keepers): rate = (keepers / total) * 100 return round(rate, 1) result = keeper_rate(840, 92) print(f"Keeper rate: {result}%") # → Keeper rate: 11.0%
सामान्य नियम: अगर आप एक ही कोड दो बार लिखते हैं, तो उसे एक फ़ंक्शन बना दें।

5. CSV फ़ाइलें पढ़ना

📂 इस पाठ में इस्तेमाल डेटासेट: photographers.csv

CSV का मतलब है Comma-Separated Values। आपका आर्काइव डेटा CSV फ़ाइलों में रहता है। यह पाठ दिखाता है कि Python से उन्हें कैसे खोलें और पढ़ें।

import csv # photographers डेटासेट खोलें with open("photographers.csv", "r") as file: reader = csv.DictReader(file) for row in reader: print(row["name"], "—", row["specialty"])

photographers.csv की संरचना

photographer_id, name, country, specialty 1, Amara Diallo, Senegal, Wildlife 2, Carlos Mendez, Brazil, Street 3, Priya Nair, India, Portrait
DictReader हर पंक्ति को एक डिक्शनरी की तरह पढ़ता है — इसलिए आप कॉलम को नाम से एक्सेस करते हैं, पोज़िशन से नहीं। पढ़ने में बहुत आसान।

6. Pandas DataFrames

📂 इस पाठ में इस्तेमाल डेटासेट: photographers.csv · shoots.csv

Pandas एक Python लाइब्रेरी है जो आपके CSV को एक शक्तिशाली टेबल में बदल देती है जिसे आप डेटाबेस की तरह क्वेरी कर सकते हैं।

import pandas as pd # डेटासेट लोड करें df = pd.read_csv("shoots.csv") # पहली 5 पंक्तियाँ देखें print(df.head()) # कितनी पंक्तियाँ और कॉलम हैं? print(df.shape) # → (103, 10) # कॉलम के नाम print(df.columns)

shoots.csv structure

shoot_id, photographer_id, event, location, year, photos_taken, photos_exported 1, 1, Serengeti Safari, Shanghai, 2021, 652, 132 2, 1, Wildlife Reserve Shoot, Kyiv, 2024, 165, 100 3, 1, Migration Season, Kolkata, 2023, 744, 128
103 पंक्तियाँ — यही है आपका पूरा आर्काइव। Pandas इसे तुरंत संभाल लेता है, चाहे 103 पंक्तियाँ हों या 103 मिलियन।

7. शूट्स फ़िल्टर करना

📂 इस पाठ में इस्तेमाल डेटासेट: shoots.csv

फ़िल्टरिंग आपको अपने डेटा से सवाल पूछने देती है। कौन सी शूट्स डाकार में थीं? किस साल सबसे ज़्यादा फ़ोटो ली गई? इन्हें एक लाइन में ढूँढें।

import pandas as pd df = pd.read_csv("shoots.csv") # डाकार की सभी शूट्स dakar = df[df["location"] == "Dakar"] print(dakar) # 2020 के बाद की सभी शूट्स recent = df[df["year"] > 2020] print(recent.head()) # 1000 से ज़्यादा फ़ोटो वाली शूट्स heavy = df[df["photos_taken"] > 1000] print(f"Heavy shoots: {len(heavy)}")

& (और) या | (या) का उपयोग करके फ़िल्टर जोड़ें:

# डाकार और 2020 के बाद filtered = df[(df["location"] == "Dakar") & (df["year"] > 2020)] print(filtered)
यही है असली ताक़त। 103 रिकॉर्ड पर भी, कोड की एक लाइन स्प्रेडशीट में स्क्रॉल करने से बेहतर है — और यह उसी तरह लाखों तक भी स्केल करती है।

8. विज़ुअलाइज़ेशन

📂 इस पाठ में इस्तेमाल डेटासेट: shoots.csv · photographers.csv

Matplotlib आपके डेटा को चार्ट में बदल देता है। अपने आर्काइव को एक नज़र में देखें — प्रति साल शूट्स, स्थान, कीपर रेट।

import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv("shoots.csv") # प्रति साल शूट्स गिनें by_year = df.groupby("year")["shoot_id"].count() # इसे प्लॉट करें by_year.plot(kind="bar", color="#6bcf8a") plt.title("प्रति साल शूट्स") plt.xlabel("साल") plt.ylabel("शूट्स की संख्या") plt.tight_layout() plt.show()
आपने फाउंडेशन पूरी कर ली है। वेरिएबल → लिस्ट → लूप → फ़ंक्शन → CSV → Pandas → फ़िल्टर → विज़ुअलाइज़। यही है पूरा पाइपलाइन। आपका आर्काइव अब प्रोग्रामेबल है।
